Simulación de Panadería (Caso Fijo)

Cola de un solo servidor. Llegadas ∼ Exponencial (media 3 min) y servicio ∼ Uniforme [2,4]. Simulamos 6 clientes.

Parámetros y fórmulas

Llegadas (Exponencial, media = 3):

T = −λ · ln(U), λ = 3, U ∈ (0,1)

Servicio (Uniforme [2,4]):

S = a + (b − a)·U, a = 2, b = 4

Política: FIFO, servidor único. Reglas:
inicio[i] = max(llegada[i], fin[i−1]) · fin[i] = inicio[i] + servicio[i] · espera[i] = inicio[i] − llegada[i]
